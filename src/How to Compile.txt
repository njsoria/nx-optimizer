Official builds use Python 3.11.x (see .github/workflows/build-multiplatform.yml). From this src/ directory:

1) Install dependencies (recommended: use a venv)

   python -m venv .venv
   source .venv/bin/activate     # macOS / Linux
   python dependencies.py

   dependencies.py installs pyinstaller, ttkbootstrap fork, tkinterdnd2, and the rest of the stack.

2) Build (macOS): matches CI — produces a zip under dist/ containing NX Optimizer.app

   python compile_onedir.py

   If GUI/LOGO.icns is missing, the build still runs; an icon is only passed to PyInstaller when that file exists.

3) Run without packaging (debug)

   python run.py

Ryujinx on macOS (short)

- Mods are installed under the Ryujinx data directory (not your game ROM folder): mods/contents/<title-id>/...
- Default data path: ~/Library/Application Support/Ryujinx/
- Portable Ryujinx: a "portable" folder next to the Ryujinx binary. On macOS you can set the path to the real binary in TOTKOptimizer.ini, e.g.
  [Paths]
  RyujinxPath = /path/to/Ryujinx.app/Contents/MacOS/Ryujinx
  Settings and logs for this app: ~/.totk-mods/TOTKOptimizer.ini and ~/.totk-mods/logger.log
